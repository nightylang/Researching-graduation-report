# Graduation Research Project Workflow Timeline
**Major:** Computer Science  
**Focus:** Cross-Regional Infrastructure & Telemetry Adaptability Model (USA-Cambodia)  
**Stack:** C# ASP.NET Core MVC & Microsoft SQL Server

---

## 📅 The 4-Week High-Speed Research & System Sprint

*   [Week 1: Foundations] ──> [Week 2: Literature & CRUD] ──> [Week 3: Methodology] ──> [Week 4: Defense Prep]

---

### 🗓️ Week 1: Project Initiation & Background Formalization
*   **Research Focus:** Complete **Chapter 1: Introduction**. Establish the core differences between the high-cost USA cloud architectures and Cambodian SME local-hosting realities. 
*   **System Action:** Execute the relational database schema in SQL Server Management Studio (SSMS). Ensure all database indexes and primary/foreign keys are activated.
*   **Weekly Deliverable:** Section 1.1 (Background), Section 1.2 (Problem Statement), Section 1.3 (Objectives), and the live populated database instance.

### 🗓️ Week 2: Literature Evaluation & CRUD Development
*   **Research Focus:** Complete **Chapter 2: Literature Review**. Analyze existing software patterns regarding network-level fraud prevention and why ACID-compliant relational databases prevent state corruption under localized network drops.
*   **System Action:** Code the central `DatabaseHelper.cs` to handle global dependency injection. Build out the backend `EmployeeController.cs` and the front-end Admin view layout.
*   **Weekly Deliverable:** Section 2.1 (USA vs Cambodia Architecture Comparison), Section 2.2 (Time-Theft Mitigation Analysis), and a functioning identity creation panel.

### 🗓️ Week 3: Methodology Mapping & Telemetry Handshake
*   **Research Focus:** Complete **Chapter 3: Research Methodology**. Document your formal system architecture charts, Entity-Relationship Diagrams (ERD), validation pseudocode, and performance test targets.
*   **System Action:** Code the `CheckInController.cs` network telemetry validation engine. Deploy the mobile-responsive Razor view to intercept connection IP addresses (`RemoteIpAddress`).
*   **Weekly Deliverable:** Section 3.1 through 3.5 (Methodology parameters) and the complete anti-buddy-punching security gate logic.

### 🗓️ Week 4: System Benchmarking & Writing Synthesis
*   **Research Focus:** Complete **Chapter 4 (Implementation Details)** and **Chapter 5 (Evaluation & Results)**. Run stress testing scripts simulating peak user check-ins. Convert latency and security detection logs into data charts.
*   **System Action:** Code freeze. Stop adding features. Configure your Windows Server local network settings (TCP Port 1433) to ensure local machine demonstrations run with 100% stability.
*   **Weekly Deliverable:** Chapter 4 code maps, Chapter 5 performance evaluation graphs, and the final thesis presentation slide deck.

## 📘 Thesis Structural Map & Target Metrics

| Thesis Component | Target Content & Architectural Deliverables | Document Weight |
| :--- | :--- | :--- |
| **Chapter 1: Introduction** | Contextualize USA Cloud vs Cambodian On-Premise constraints. Outline objectives to eliminate hardware dependencies. | 15% |
| **Chapter 2: Literature Review** | Justification of C# MVC design principles. Academic analysis of IP-subnet geofencing versus physical biometrics. | 20% |
| **Chapter 3: Methodology** | Normalized Database Schema, Star-schema description text, validation pseudocode, and testing metrics. | 25% |
| **Chapter 4: Implementation** | Deployment configurations, system topology charts, core controller snippets, and user interface screenshots. | 20% |
| **Chapter 5: Evaluation** | Latency benchmarks (**Target < 250ms**), database write speeds (**Target < 50ms**), and fraud detection rates (**Target 100%**). | 15% |
| **Chapter 6: Conclusion** | Summary of contributions to Cambodian SME infrastructure design and recommendations for future offline data sync layers. | 5% |

## 🛠️ Research & Implementation Execution Routine

*   **Mondays (Ingestion):** Gather reading material on cross-regional IT adaptabilities. Verify that data tables are synchronized.
*   **Tuesdays & Wednesdays (Development):** Focus purely on back-end C# routing logic, SQL parameters, and front-end interface layouts.
*   **Thursdays (Drafting):** Write text into your thesis chapters while the code logic is fresh in your memory. Never write code without immediately documenting it.
*   **Fridays (Benchmarking):** Run local server runtime checks. Monitor log exceptions, address SQL database constraints, and optimize controller code loops.
*   **Saturdays (Advisor Review):** Compile your weekly progress into clean PDF summaries and submit your latest chapter revisions to your committee advisor for evaluation.
